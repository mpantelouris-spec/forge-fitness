# Forge — Fitness, Nutrition & Recipes

A science-based fitness tracker that runs entirely in your browser and installs as an app on phone or desktop.

**Open the app:** https://mpantelouris-spec.github.io/forge-fitness/

## Install it
- **iPhone / iPad (Safari):** Share button → *Add to Home Screen*
- **Android (Chrome):** ⋮ menu → *Install app* / *Add to Home screen*
- **Windows / Mac (Chrome or Edge):** install icon in the address bar, or ⋮ → *Install Forge*

## Features
- Food log with USDA-based foods, custom foods and macro-accurate recipes (scaling, shopping list)
- Gym & home workouts, multi-week programs, live workout mode with rest timer and progressive-overload suggestions
- Calories burned (Compendium of Physical Activities METs, net of resting burn), adaptive TDEE
- Weight trend, body-fat (U.S. Navy), PRs, weekly muscle volume, calculators (1RM, plates, HR zones, pace/VDOT)
- Works offline; all data is stored only on your device (export/import backups in Profile)
